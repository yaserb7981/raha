# 🕊️ رها — راهنمای سریع

ترکر ۹۱ روزه‌ی ترک پورن و خودارضایی. سه حالت داره؛ هر کدام را خواستی استفاده کن.

---

## ۱) نسخه‌ی آفلاین (تک‌فایلی) — ساده‌ترین و مطمئن‌ترین
فایل: **رها — نسخه آفلاین (یک فایل).html**

1. فایل را روی گوشی یا کامپیوتر ذخیره کن.
2. با مرورگر (Chrome / Safari / Edge) بازش کن.
3. تمام. بدون اینترنت، بدون نصب، بدون سرور کار می‌کند.

- داده‌ها در حافظه‌ی همان مرورگر ذخیره می‌شوند.
- **هر چند روز یک‌بار**: تنظیمات → «خروجی JSON» → فایل بکاپ را جای امن نگه دار.
- انتقال به گوشی دیگر: همان فایل بکاپ را با «بازیابی از فایل» وارد کن.

---

## ۲) نسخه‌ی سرور (همیشه‌روشن، چند دستگاه، سینک)
فایل: **رها — پروژه کامل.zip**

```bash
cd raha
python3 server.py        # → http://localhost:8000
```
هیچ نصب دیگری لازم نیست (فقط پایتون ۳).

### سینک بین گوشی و کامپیوتر (دقیقاً همان چیزی که می‌خواستی)
1. روی کامپیوتر: `python3 server.py` را اجرا کن.
2. در نسخه‌ی سرور: تنظیمات → **همگام‌سازی** → «ساخت توکن سینک» → آدرس و توکن را کپی کن
   (آدرس روی شبکه‌ی خانه: `http://192.168.1.42:8000`).
3. در نسخه‌ی آفلاین (گوشی): تنظیمات → **همگام‌سازی** → همان آدرس و توکن را بچسبان →
   «همگام‌سازی الان». تیک «خودکار» را بزن تا هر بار که آنلاین شدی خودش سینک کند.

ادغام دوطرفه است (Last-Write-Wins بر اساس زمان ویرایش):
- چیزی که آفلاین ثبت کردی → می‌رود روی سرور
- چیزی که روی سرور ثبت شد → می‌آید روی گوشی
- هیچ داده‌ای پاک نمی‌شود؛ حذف‌ها هم به‌صورت «حذف‌شده» سینک می‌شوند.

## ۳) نسخه‌ی PWA (نصب‌شدنی روی گوشی)
پوشه‌ی `offline/pwa` داخل zip → روی GitHub Pages یا Cloudflare Pages بذار →
از مرورگر «افزودن به صفحه اصلی» → آیکون + تمام‌صفحه + کش آفلاین.

---

## گوگل درایو
- **بکاپ دستی:** تنظیمات → خروجی JSON → فایل را در همین پوشه‌ی درایو بگذار (یا داخل پوشه‌ی Google Drive Desktop روی کامپیوتر).
- **بکاپ خودکار (ویندوز/مک):** پوشه‌ی `data` پروژه را داخل پوشه‌ی «Google Drive» کپی کن، یا این را در cron/Task Scheduler بگذار:
  ```bash
  cp /path/to/raha/data/raha.db "$HOME/Google Drive/raha-backup-$(date +%F).db"
  ```
- **اتصال مستقیم به_API گوگل:** نیاز به ساخت پروژه در Google Cloud و OAuth دارد (برای این اپ لازم نیست؛ همان دو روش بالا کافی و امن‌تر است).

## نکته‌ی مهم
این اپ جای درمان را نمی‌گیرد. اگر مصرف اجباری و خارج از کنترل است یا نشانه‌های افسردگی/اضطراب داری، با یک روان‌شناس صحبت کن.

## 🗓️ یادآور روی گوشی/گوگل کلندر

تنظیمات → کارت «تقویم · یادآورِ وابسته به اپ» → **ساخت فایل تقویم (.ics)** → یک بار Import.
فایل از دادهٔ همین اپ ساخته می‌شود (امروز تا روز ۹۱ + سه نقطهٔ عطف). اگر روزشماری عوض شد، دوباره بساز و دوباره Import کن؛ رویدادها به‌روز می‌شوند، کپی نمی‌شوند.

## ☁️ پشتیبان خودکار روی گیت‌هاب (رمزنگاری‌شده)

تنظیمات → «پشتیبان خودکار روی گیت‌هاب» → owner/repo + توکن (`Contents: Read and write`) + یک رمز → تیک «هر روز خودکار».
- خروجی رمزنگاری‌شده (AES-GCM) در `backup/raha-backup.enc` و یک نسخهٔ روزانه در `backup/history/`.
- «بازیابی از گیت‌هاب» همان فایل را رمزگشایی و جایگزین می‌کند.
- توکن و رمز فقط در همان مرورگر می‌مانند و هرگز در فایل پشتیبان نمی‌روند.
